## Project Overview

Sweet Crumbs Bakery is a fictional local bakery based in Johannesburg, South Africa. The website has been developed to provide customers with information about the bakery, its products and services, and ways to make enquiries or place order requests.

The website is designed to be simple, informative and easy to navigate. It includes a homepage, About Us page, Products page, Services page, Gallery page, Contact Us page and Order Enquiry page.

## Website Goals and Objectives

The main goals of the website are to:

- Provide information about Sweet Crumbs Bakery.
- Display the bakery's products and services.
- Allow customers to make enquiries.
- Allow customers to submit order enquiries.
- Provide easy navigation between all website pages.
- Create a professional online presence for the bakery.

## Key Features and Functionality

The website includes:

- Home page with an introduction to the bakery.
- About Us page containing the bakery's mission and vision.
- Products page displaying available baked products.
- Services page describing bakery services.
- Gallery page displaying bakery images.
- Contact Us page with contact details and an enquiry form.
- Order Enquiry page with an order form.
- Navigation menu linking all pages.
- External CSS stylesheet for consistent styling.
- Images stored in a dedicated images folder.
